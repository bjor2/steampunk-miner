# Standards

`REFERENCE.md` and `CHECKLIST.md` are copied verbatim from Osilion's house style skill
`osilion-dev-tsr3f` (TypeScript + React Three Fiber). They are the long form of the six rule
groups summarised in [CLAUDE.md](../../CLAUDE.md). If the skill changes, re-copy the files; do not
edit them here. Where this repo's `CLAUDE.md` or [TESTING_INSTRUCTIONS.md](../TESTING_INSTRUCTIONS.md)
says otherwise, those win.

- [REFERENCE.md](REFERENCE.md) – the rules with before/after code
- [CHECKLIST.md](CHECKLIST.md) – review checklist, run over every touched file

This repo's own standards sit beside them:

- [feature-slices.md](feature-slices.md) – where feature code lives and how slices reach the kernel (#155)
- [slice-template.md](slice-template.md) – how to start a slice; `src/features/example/` is its copy
